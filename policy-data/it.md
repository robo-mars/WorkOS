# IT support and equipment
Policy ID: it · Owner: IT Services · Reviewed: 2026-10-01
Request a monitor, keyboard, laptop, or other equipment with a hardware ticket. Describe the issue and business impact. Software installation requests use the software category; VPN or connectivity issues use network. Never include passwords, security codes, or API keys in ticket descriptions. High priority is reserved for work-blocking incidents. Ticket status can be checked with the ticket ID.
